# Training runs

All training runs on Kaggle GPUs in private notebooks (private because the Indian Driving Dataset is
licensed for research use only and the plate images show real registrations). Notebooks are
generated by [`kaggle/make_train.py`](../kaggle/make_train.py); the generated notebook and its Kaggle
metadata are in [`kaggle/train-vehicles/`](../kaggle/train-vehicles) and
[`kaggle/train-plates/`](../kaggle/train-plates). Weights are not committed (`*.pt` is ignored); they are
the notebooks' outputs.

## How a run works

1. **Prepare data**: link every image into one YOLO dataset, rewriting each label file to the target
   classes (other classes' boxes are removed, the image stays). Small local sets are repeated
   (x2-x5) so they are not drowned by the large Indian set. The preparation step was checked
   locally on mock copies of each dataset's layout before the first GPU run.
2. **Train**: Ultralytics YOLO11s from COCO-pretrained weights, 640 px, batch 32, seed 0, early stop
   after 12 epochs without improvement, wall-clock cap.
3. **Evaluate per source**: mAP on each dataset's validation images separately, so a strong score on
   the large Indian set cannot hide a weak one on the Nepali images.
